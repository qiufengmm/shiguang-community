# 23.3 评论发布接口

- 扩展 MyBatis Generator 配置，并从 Biz 模块目录运行生成器，生成 `t_comment`、`t_comment_like` 的 DO、Mapper 与 XML；DO 按教程改为 Lombok、`LocalDateTime` 和 Boolean/Integer 字段。
- 新增 `POST /comment/publish`、请求 VO、全局异常处理、响应码、评论 MQ DTO/Topic 常量和 RocketMQ 配置。评论正文与图片均为空时返回 `COMMENT-10001`；有效请求携带当前用户 ID 异步发送到 `PublishCommentTopic`。
- 按教程给 Gateway 添加 `lb://xiaohashu-comment` 路由和 `StripPrefix=1`。
- 验证：服务层 2 项测试通过；JDK 17 下 comment API/Biz 与 Gateway 打包成功。直接调用评论接口验证空内容校验和有效发布；RocketMQ 回调 `SEND_OK`，抽查消息确认包含随机 note、reply、creator ID 与时间。测试 topic 创建前不存在，验证后已删除，没有写入 MySQL/Cassandra 测试记录。
- **教程路由风险：**教程的 Gateway 路由对 `/comment/**` 使用 `StripPrefix=1`，但 Controller 保留 `/comment/publish` 前缀；从 `/comment/publish` 转发会变为 `/publish`，与 Controller 不匹配。按要求保留教程配置。网关实测请求因缺少登录 token 先返回 401，未完成认证后的转发验证；建议后续确认实际访问路径，再统一是否剥离前缀。
