# 20.8 Elasticsearch 安装 ik 中文分词器插件

教程正文：`F:\code\xiaohashu\教程\20 Elasticsearch 分布式搜索引擎\20.8 Elasticsearch 安装 ik 中文分词器插件.md`。

## 安装

ES 7.3.0 对应 ik 7.3.0，在容器内执行：

```bash
docker exec -it es7 bin/elasticsearch-plugin install https://get.infini.cloud/elasticsearch/analysis-ik/7.3.0
```

安装后把插件与配置复制到宿主机挂载目录，防止容器重建后丢失：

```bash
docker cp es7:/usr/share/elasticsearch/plugins/analysis-ik E:\docker\elasticsearch\plugins
docker cp es7:/usr/share/elasticsearch/config/analysis-ik E:\docker\elasticsearch\config
docker restart es7
```

## 两种分词模式

| 模式 | 粒度 | 用途 |
| --- | --- | --- |
| `ik_max_word` | 最细粒度，穷举组合 | 索引时使用 |
| `ik_smart` | 最粗粒度 | 查询时使用 |

## 本次核对

插件与词典都已在位，无需重装：

- `F:\docker\elasticsearch\plugins\analysis-ik\` 下有 `elasticsearch-analysis-ik-7.3.0.jar`
- `F:\docker\elasticsearch\config\analysis-ik\` 下有 `IKAnalyzer.cfg.xml` 与 `main.dic`、`stopword.dic`、`extra_main.dic` 等词典（第 21 章自定义分词字典、停用词要用到）
