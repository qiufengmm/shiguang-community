# 20.4 Docker 安装 Kibana

教程正文：`F:\code\xiaohashu\教程\20 Elasticsearch 分布式搜索引擎\20.4 Docker 安装 Kibana.md`。

## 容器

| 容器 | 镜像 | 端口 | 挂载 |
| --- | --- | --- | --- |
| `kibana` | `kibana:7.3.0` | 5601 | `F:\docker\kibana\config` |

```bash
docker run -d --name kibana -p 5601:5601 -v E:\docker\kibana\config:/usr/share/kibana/config kibana:7.3.0
```

## kibana.yml

`F:\docker\kibana\config\kibana.yml` 内容：

```yaml
server.name: kibana
server.host: "0"
elasticsearch.hosts: [ "http://172.17.0.1:9200" ] # 修改为宿主机 IP 地址
i18n.locale: "zh-CN" # 设置使用中文
xpack.monitoring.ui.container.elasticsearch.enabled: true
```

`elasticsearch.hosts` 用宿主机在 Docker bridge 网络里的地址 `172.17.0.1`，而不是容器名——ES 容器叫 `es7`，Kibana 与它不在同一个自定义网络里，用容器名解析不到。

## 本次核对

原配置里 `elasticsearch.hosts` 指向 `http://elasticsearch:9200`，这个主机名在本机不存在。已按教程改成 `http://172.17.0.1:9200` 并补上 `i18n.locale: "zh-CN"`，然后 `docker restart kibana`。
