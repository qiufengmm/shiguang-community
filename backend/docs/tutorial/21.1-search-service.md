# 21.1 搜索服务搭建

- 新增 Maven 子模块 `xiaohashu-search`，按教程引入公共组件、Web、Bootstrap 与 Nacos Discovery 依赖。
- 服务监听 8092，应用名为 `xiaohashu-search`，注册到 Nacos 的 `xiaohashu` 命名空间。
- 增加 Spring Boot 启动类、dev/prod 配置占位文件，并沿用项目 Logback 配置，将日志应用名设为 `search`。
- 验证：使用 JDK 17 编译打包；启动服务，确认 8092 可访问且 Nacos 注册列表出现 `xiaohashu-search`。
