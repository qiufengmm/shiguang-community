# 24.3 评论热度值计算

- 评论表增加 `heat` 字段；计数服务在一级评论的二级评论数更新后，异步发送 `CommentHeatUpdateTopic`。
- 评论服务使用 BufferTrigger 聚合消息并去重评论 ID，批量查询点赞数和子评论数，按 `点赞数 × 0.7 + 子评论数 × 0.3` 四舍五入到两位小数后批量更新热度。
- 验证：JDK 17 下 JSON Set 解析、热度计算、消息 ID 去重 3 项测试通过；count/comment 服务打包并启动成功。实际发布 1 条一级评论和 3 条二级评论，将一级评论点赞数设为 10，数据库验证 `child_comment_total=3`、`heat=7.90`。MySQL 测试行、计数行和 Cassandra 分区均已清理。
- 本机 Docker MySQL 已执行本节 DDL；对应脚本保存在 `database/24.3-comment-heat.sql`。
