# 25.9 KV 服务：评论正文删除接口开发

## 本节实现

- 在 KV API 新增 `DeleteCommentContentReqDTO`，校验笔记 ID、年月和正文 UUID。
- 为 `CommentContentRepository` 增加按 `noteId`、`yearMonth`、`contentId` 删除 Cassandra 评论正文的方法。
- 在 `CommentContentService`、Controller 与 `KeyValueFeignApi` 增加删除操作，服务层将 UUID 字符串转换为 `UUID` 后调用 repository。

## 验证

- JDK 17 下 KV API 与 KV Biz 共 15 项测试全部通过，包含 Feign 合约和 Cassandra HTTP 集成测试。
- 通过 `spring-boot:run` 在 18084 启动当前代码；保留了原先占用 8084 的进程。
- 实测向 Cassandra 写入随机正文，调用 `/kv/comment/content/delete` 后再查询，返回成功且正文列表为空；测试数据已清理。
- 实现遵循教程。
