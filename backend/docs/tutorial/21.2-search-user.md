# 21.2 整合 Elasticsearch 客户端并开发用户搜索

- 在父 POM 统一管理 Elasticsearch 7.3.0 客户端依赖；搜索服务读取 `127.0.0.1:9200` 并创建 `RestHighLevelClient`。
- 新增用户搜索请求/响应 VO、索引字段常量、用户搜索服务和 `POST /search/user` 控制器，并按教程加入参数校验与全局异常响应。
- 查询 `user` 索引的 `nickname`、`xiaohashu_id` 字段，按粉丝数倒序分页，每页 10 条。
- 验证：先确认接口返回 404；JDK 17 打包成功后重启服务，用现有 Elasticsearch 索引搜索到 2 条结果；空关键词返回 `SEARCH-10001`；Nacos 实例健康且监听 8092。
- 观察：现有 `user` 索引文档的头像、笔记数和粉丝数为 `null`，本节按教程原样返回。教程还会捕获 ES 查询异常后返回 `PageResponse.success(null, ...)`；ES 故障时 `data` 可能为 `null`，本节保留教程实现，后续可再修正。
