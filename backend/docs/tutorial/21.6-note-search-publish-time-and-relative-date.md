# 21.6 笔记搜索发布时间范围与相对时间

- 为搜索请求增加 `publishTimeRange`，支持一天、一周、半年三个范围，并在 Elasticsearch `create_time` 字段上追加 range filter。
- 扩展日期工具，支持 `LocalDateTime` 转字符串及相对时间格式；搜索结果将更新时间展示为分钟、小时、昨天、天数、月日或完整日期，并返回格式化后的评论数和收藏数。
- 验证：JDK 17 执行 `mvn -pl xiaohashu-search -am -DskipTests package` 成功；启动搜索服务后，接口实测三档时间范围、相对时间的六类展示文案以及评论/收藏数量格式。临时文档已逐条删除，`note` 索引数量恢复为 3。
- 风险：沿用 21.5 中记录的 ES `id` 直接强转 `Long` 问题；本节接口实测使用大于 32 位的随机 ID。其余按教程实现。
