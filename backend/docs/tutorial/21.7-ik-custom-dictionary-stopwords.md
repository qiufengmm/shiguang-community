# 21.7 IK 自定义扩展词典与停用词

- 复用已运行的 `es7`（Elasticsearch 7.3.0）及其现有配置挂载 `F:\docker\elasticsearch\config`，未重新安装容器。
- 在 `analysis-ik/custom/mydict.dic` 中添加“犬小哈”“小哈”，在 `analysis-ik/custom/ext_stopword.dic` 中添加“的”“呀”；更新 `IKAnalyzer.cfg.xml` 的 `ext_dict` 和 `ext_stopwords` 路径，并按教程重启 `es7`。
- 验证：重启前“犬小哈教程”分词为“犬/小/哈/教程”；重启后为“犬小哈/教程”。“犬小哈的教程呀”重启后同样为“犬小哈/教程”，扩展停用词已生效。ES 单节点状态为 yellow，搜索服务接口在 ES 重启后恢复正常。
- 配置文件位于 Docker 的宿主机挂载目录，保存于本机环境；仓库提交仅记录本节实施与验证结果。
