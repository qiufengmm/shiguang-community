# 20.2 Docker 安装 Elasticsearch 7.x 与 head

教程正文：`F:\code\xiaohashu\教程\20 Elasticsearch 分布式搜索引擎\20.2 Docker 安装 Elasticsearch 7.x 以及 head 可视化工具.md`。

## 容器

| 容器 | 镜像 | 端口 | 挂载 |
| --- | --- | --- | --- |
| `es7` | `elasticsearch:7.3.0` | 9200、9300 | `F:\docker\elasticsearch\{config,data,plugins,logs}` |
| `es-head` | `mobz/elasticsearch-head:5-alpine` | 9100 | 无 |

ES 以 `discovery.type=single-node` 单节点运行，堆内存固定 `ES_JAVA_OPTS="-Xms1024m -Xmx1024m"`。

启动命令（挂载版本）：

```bash
docker run -d --name es7 -p 9200:9200 -p 9300:9300 \
  -e "discovery.type=single-node" -e ES_JAVA_OPTS="-Xms1024m -Xmx1024m" \
  -v E:\docker\elasticsearch\config:/usr/share/elasticsearch/config \
  -v E:\docker\elasticsearch\data:/usr/share/elasticsearch/data \
  -v E:\docker\elasticsearch\plugins:/usr/share/elasticsearch/plugins \
  -v E:\docker\elasticsearch\logs:/usr/share/elasticsearch/logs \
  elasticsearch:7.3.0

docker run -d --name es-head -p 9100:9100 mobz/elasticsearch-head:5-alpine
```

## elasticsearch.yml

`F:\docker\elasticsearch\config\elasticsearch.yml` 内容：

```yaml
cluster.name: "xiaohashu-cluster"
network.host: 0.0.0.0
# 跨域相关
http.cors.allow-origin: "*"
http.cors.enabled: true
http.cors.allow-headers: Authorization,X-Requested-With,Content-Length,Content-Type
```

跨域配置是为了让 es-head（9100）能直接请求 9200。

## 本次核对

容器已经按挂载方式在跑，但 `elasticsearch.yml` 还是镜像默认内容（`cluster.name: "docker-cluster"`，没有跨域配置）。已按教程补齐后 `docker restart es7`——配置目录是挂载出来的，重启即生效，不需要 `docker rm -f` 重建，已有的 `note` 索引数据保留。
