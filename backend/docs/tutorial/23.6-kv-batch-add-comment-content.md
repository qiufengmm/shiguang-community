# 23.6 KV 批量新增评论正文

- 在 KV API 增加批量评论请求 DTO 和 Feign 方法；KV Biz 增加 Cassandra DO、复合主键、Service 与 `POST /kv/comment/content/batchAdd` Controller，并补入教程要求的 operation-log、Jackson starter。
- 请求集合不能为空，且集合中的每条评论都校验 noteId、yearMonth、contentId 和 content。业务层将 contentId 转 UUID，按 `(note_id, year_month, content_id)` 主键映射后使用 `CassandraTemplate.batchOps().insert(...).execute()` 批量写入。
- 验证：JDK 17 下 KV API/Biz 打包成功；KV 服务在 8084 启动并注册 Nacos。空评论集合返回 `KV-10001`；两条随机评论成功写入 Cassandra，原样重复请求后仍只有两行；已删除随机分区并确认行数为 0。
- Cassandra 目标表与教程主键结构一致：`PRIMARY KEY ((note_id, year_month), content_id)`。
