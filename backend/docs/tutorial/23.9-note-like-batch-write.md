# 23.9 笔记点赞、取消点赞批量写库

- 将 note 服务的 `LikeUnlikeNoteConsumer` 改为 RocketMQ 有序批量消费者，最多每批 30 条；在批次内按用户、笔记分组，偶数次操作抵消，奇数次保留最后一次状态，再通过联合唯一键批量 upsert `t_note_like`。
- count 服务的点赞计数消费者改为使用独立 Group 并行订阅 `LikeUnlikeTopic`，从接口原始消息独立聚合笔记与作者计数。note 服务新增 `rocketmq-client` 依赖及 `batchInsertOrUpdate` MyBatis SQL。
- 为测试操作合并，将教程内联逻辑提取为 package-private `mergeOperations`；行为与教程一致。先写测试并确认缺少方法时编译失败，再实现；合并单测 3 项通过，覆盖偶数抵消、奇数取末次、不同用户/笔记不互相抵消。
- 验证：JDK 17 下 note、count 两模块打包成功。启动 note（8086）与 count（8090），通过真实 `/note/like` 接口并发点赞 10 篇临时笔记：10 个请求均成功，MySQL 中 10 条点赞状态为 1、10 条笔记计数为 1、作者点赞计数为 10；note 日志显示一次 9 行多值 upsert。另通过真实 like → unlike 验证已有记录更新为 0、笔记和作者计数回到 0。count 日志确认独立消费原始 `LikeUnlikeTopic` 并写入计数。
- 测试创建的笔记、点赞、笔记计数、用户计数均已删除；Redis Bloom、ZSet 与临时笔记详情 key 也已清理。无业务行为偏离教程。
