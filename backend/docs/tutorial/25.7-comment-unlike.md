# 25.7 取消评论点赞接口开发

## 本节实现

- 新增 `UnLikeCommentReqVO` 与 `POST /comment/unlike`，并在 `CommentService` 中声明取消点赞业务方法。
- 新增 `bloom_comment_unlike_check.lua` 与 `CommentUnlikeLuaResultEnum`，用 Bloom Filter 识别过滤器缺失、已点赞和未点赞状态。
- Bloom Filter 不存在时，异步重建用户点赞集合并查询 MySQL；确认没有点赞记录时返回 `COMMENT-20003`。
- 点赞确认后发送按用户 ID 分区的顺序 MQ，消息类型为 `UNLIKE`、标签为 `UnLike`，由 25.6 的消费者批量删除数据库记录。

## 验证

- JDK 17 下 comment-biz reactor 测试 31 项全部通过；项目既有 RocketMQ 集成测试 `MQTests` 按约定排除。
- Maven `-DskipTests package` 成功，评论服务在 8093 端口启动，RocketMQ 评论点赞消费者在线。
- 通过运行中的接口先调用 `/comment/like` 再调用 `/comment/unlike`：两次响应均成功，Docker MySQL 点赞记录从 1 条变为 0 条。
- 测试后删除随机评论、点赞数据与 Bloom key，复核剩余数量均为 0。
- 实现遵循教程，未偏离。
