# 25.4 评论点赞接口开发（1）

## 本节实现

- 新增 `POST /comment/like`，先校验评论存在，再调用 RedisBloom Lua 脚本判断用户是否点赞过，并按用户 ID 有序发送 `CommentLikeUnlikeTopic:Like` 消息。
- 添加点赞请求 VO、MQ DTO、Lua 返回值枚举、点赞类型枚举，以及用户维度的 Bloom Filter Key。
- 计数服务消费评论数变更消息时，如果笔记计数 Hash 已存在，同步递增 `commentTotal` 字段，再更新 MySQL。

## 验证

- JDK 17 下 Maven reactor 测试：comment-biz 20 项、count-biz 11 项全部通过；`MQTests` 被排除（该测试此前因 RocketMQ broker 流控失败，与本节改动无关）。
- comment-biz 与 count-biz 均完成 Maven 打包，并分别以新 jar 启动；8093、8090 端口正常，服务成功注册到 Nacos。
- 对 RedisBloom 脚本实测：Bloom Key 不存在返回 `-1`，首次加入评论 ID 返回 `0`，重复加入返回 `1`；临时 Bloom Key 已删除。
- 实际请求 `/comment/like`，传入随机且不存在的评论 ID，接口返回 `COMMENT-20001`；该路径未发送 MQ 消息。
