# 25.1 二级评论分页接口（1）

- 新增 `POST /comment/child/list`，从一级评论的 `child_comment_total` 读取总数，分页查询二级评论并跳过一级评论列表已经展示的首条回复；批量查询评论正文和用户资料，回复到二级评论时返回被回复用户昵称与 ID。
- 验证：JDK 17 下评论模块 reactor 测试 15 项通过并打包成功。8093 接口用随机测试数据返回了两条后续回复，正确跳过首条回复，正文和回复用户 ID 均正确；MySQL、Cassandra 测试数据已清理。
- 按教程实现，未擅自修正。教程当前逻辑对空分页结果或全图片评论仍会调用要求非空 Key 列表的 KV 接口；最多 6 条评论还可能产生 12 个不同用户 ID，超过用户批量查询最多 10 个的限制；回复目标用户资料缺失时会解引用空对象。无评论分支沿用三参数分页响应，其 pageSize 为公共默认值 10，而此接口正常 pageSize 为 6。
