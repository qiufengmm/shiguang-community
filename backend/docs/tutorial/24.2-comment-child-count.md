# 24.2 计数服务：二级评论总数更新

- `t_comment` 增加 `child_comment_total` 字段，计数服务新增 `CommentDO` Mapper，并按 `level=1` 累加父评论的二级评论数。
- 评论服务发往 `CountNoteCommentTopic` 的 DTO 增加 `level`、`parentId`；计数服务用独立消费者组订阅同一 Topic，只汇总二级评论。
- 验证：JDK 17 下 count/comment 单测 6 项通过，两个服务打包成功。真实发布 1 条一级评论、2 条二级评论，其中第二条回复第一条二级评论；数据库确认两条二级评论的 `parent_id` 都指向一级评论，`child_comment_total=2`，笔记 `comment_total=3`。临时 MySQL/Cassandra 记录已清理。
- 本机 Docker MySQL 已执行本节 DDL；对应脚本保存在 `database/24.2-comment-child-count.sql`。
