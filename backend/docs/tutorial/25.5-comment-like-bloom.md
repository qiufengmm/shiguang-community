# 25.5 评论点赞接口开发（2）—— 添加 Bloom 布隆过滤器

## 本节实现

- 为 `CommentLikeDOMapper` 增加按用户和评论查询点赞记录数、按用户查询全部点赞评论的方法及对应 MyBatis SQL。
- 增加重复点赞业务码 `COMMENT-20002`。
- Bloom Filter Key 不存在时，先查 MySQL：若已点赞，异步从数据库重建用户的 Bloom Filter 并返回重复点赞；若未点赞，则同步补入历史点赞，再添加当前评论并设置 1 小时加随机秒数的过期时间。
- Bloom Filter 命中时再查 MySQL确认；数据库无记录则按 Bloom 假阳性处理，继续发送点赞 MQ。
- 新增批量初始化与单条添加两个 Lua 脚本。

## 验证

- JDK 17 下 comment-biz 23 项、count-biz 11 项 reactor 测试全部通过；本节新增三条服务逻辑测试，覆盖缺失过滤器的重复点赞、Bloom 假阳性和初始化后添加当前评论。
- Maven 打包成功，评论服务和计数服务分别启动于 8093、8090 并注册到 Nacos。
- RedisBloom 实测两个新 Lua 脚本：评论 ID 加入成功，批量添加的两个 ID 均可查到，过期时间已设置；所有临时 Key 均已删除。
- 使用 Docker MySQL 写入随机评论和点赞记录，实测 `/comment/like` 返回 `COMMENT-20002`，异步初始化后的 Bloom Filter 包含目标评论并带过期时间。验证后已删除随机 MySQL 记录及 Bloom Key，逐项确认均不存在。

## 后续小节

本节按教程只完成点赞防重和 Bloom Filter 初始化。取消点赞、批量消费以及点赞计数入库由后续小节继续实现。
