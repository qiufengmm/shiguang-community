# 24.8 评论分页查询：Caffeine 本地缓存

- 评论详情在进程内增加 Caffeine 缓存：初始/最大容量 10,000，写入后 1 小时过期；数据库回源组装出的详情异步写入 Redis 和本地缓存，查询时优先读本地缓存，再批量读 Redis。
- 验证：JDK 17 下评论模块 reactor 测试 12 项通过，打包成功。服务运行于 8093；随机测试评论首次从数据库与 Cassandra 正常返回，第二次本地缓存命中也正常返回。重启清空本地缓存后，首个 Redis 回退请求正常；紧接的请求复现教程代码问题：仍返回成功，但评论列表为空。MySQL、Cassandra、Redis 测试数据已按随机 ID 清理，服务已用本节代码重新启动。
- 按教程原样实现，未擅自修正。风险：`LOCAL_CACHE.getAll()` 的缺失项映射返回空字符串会把占位值写进 Caffeine；首次 Redis 回退之后，后续请求把空字符串当作本地命中并跳过 Redis，导致列表为空，直到本地项过期或被重新写入。另一个潜在错位是 Redis MGET 缺失项回源时，教程按完整 `commentIdList` 的索引取 ID，而 MGET 只查询 `localCacheExpiredCommentIds`；若本地有命中且 Redis 某个缺失详情，则可能回源到错误评论。
