# 26.1 点赞校验方案：Bloom 改为 Bitmap 更好吗？

## 本节结论

- Redis Bitmap 按最大的 offset 分配连续位空间，适合 ID 范围紧凑、需要精确读写状态的场景。
- 小哈书的笔记 ID 可能是稀疏且很大的雪花 ID。Bitmap 的内存成本由最大 offset 决定，无法直接替代现有 Bloom 校验。
- Bloom 过滤器适合大量点赞记录，但有误判，需要在可能误判时二次查询数据库。
- 教程给出的策略是：点赞数量较少时用 Redis Set；超过配置阈值后用 Bloom 过滤器并在必要时二次校验。

本节是技术选型讨论，没有代码变更或运行验证；后续实现从 26.2 的 Roaring Bitmap 环境开始。
