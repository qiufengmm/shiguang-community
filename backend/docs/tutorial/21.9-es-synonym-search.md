# 21.9 Elasticsearch 自定义同义词搜索

- 在现有 IK 挂载目录 `F:\docker\elasticsearch\config\analysis-ik\custom\synonyms.txt` 添加同义词行 `黑猴,黑悟空,wukong`；创建教程中的 `note2` 测试索引，配置 `ik_smart`、`ik_max_word` 与 synonym filter。
- 验证：`note2` 的 title 字段分析“黑猴”时产生的词项中包含 `wukong`；新增一条随机测试笔记后，按 title=`wukong` 查询命中该笔记。测试文档已逐条删除，`note2` 索引按教程保留，文档数量为 0。
- 观察：IK 的 `ik_max_word` 将原输入拆成多个词项，`_analyze` 返回 `黑/黑/wukong/猴/悟空`；虽然没有单独输出“黑猴”词项，同义词查询仍已通过实际索引搜索验证。
- 注意：同义词文件路径位于 Docker 宿主机挂载目录，仓库仅保存本节记录；按教程，同义词文件变更后需要重建使用该分析器的索引。单节点集群中 `number_of_replicas=1` 时索引健康状态为 yellow。
