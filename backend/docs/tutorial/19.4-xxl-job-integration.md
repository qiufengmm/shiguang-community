# 19.4 Spring Boot 3 整合 XXL-JOB

按用户补充的 19.4 正文完成集成。调度中心与 `xxl-job-core` 统一使用 2.4.1，执行器标识为 `xxl-job-executor-xiaohashu`，执行器端口为 10001。

## 配置与任务

`XxlJobProperties` 绑定 `xxl.job` 配置，`XxlJobConfig` 创建 `XxlJobSpringExecutor`。`CreateTableXxlJob.createTableJobHandler()` 通过 `@XxlJob("createTableJobHandler")` 注册任务，并使用 `XxlJobHelper.log` 输出任务日志。本节按教程保留创建表的 TODO，19.5 补充实际建表逻辑。

调度中心将默认执行器改为小哈书执行器，注册方式为自动注册；将默认任务改为创建日增量表任务，Handler 使用 `createTableJobHandler`，测试 Cron 为 `0/5 * * * * ?`。运行模式为 BEAN，路由策略为 FIRST，阻塞策略为 SERIAL_EXECUTION，调度过期策略为 DO_NOTHING。

## 本机与 Docker 间的地址

调度中心在 Docker 中运行，数据对齐服务使用本机 JDK 17 启动。保留教程配置中的自动 IP 与日志默认路径，启动时可通过程序参数指定 Docker 能访问的宿主机地址及 Windows 本地日志目录：

```powershell
# 在 xiaohashu-data-align 目录运行；启动前清除 SERVER_PORT、SERVER__PORT 环境变量。
& 'D:\java\jdk-17.0.18+8\bin\java.exe' -jar target/xiaohashu-data-align-0.0.1-SNAPSHOT.jar --xxl.job.ip=host.docker.internal --xxl.job.logPath=logs/xxl-job/jobhandler
```

`host.docker.internal` 用作执行器注册地址，使调度中心容器可以连接宿主机的 10001 端口。执行器访问调度中心使用配置中的 `http://127.0.0.1:7777/xxl-job-admin`。通讯 Token 与调度中心默认值 `default_token` 保持一致。

## 验证

先确认执行器注册，再通过调度中心手动触发任务，并短暂启动 5 秒 Cron 调度；调度日志应显示成功，执行日志包含“开始初始化明日增量数据表”。验证完成后停止演示调度，保留执行器与任务定义供后续章节使用。
