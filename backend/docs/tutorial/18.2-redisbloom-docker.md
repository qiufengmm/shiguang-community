# 18.2 RedisBloom Docker 环境

教程正文：`F:\code\xiaohashu\教程\18 计数服务搭建与开发（2）\18.2 Redis 安装 Bloom 布隆过滤器模块.md`。

## 当前环境

教程要求使用 Redis 7.2.3，并加载 RedisBloom 2.2.18。当前 Docker 环境中的 `redis8` 已运行 Redis 8.10.2，启动时已加载 `bf` 模块，模块版本为 8.10.1；Redis 数据与配置分别挂载到 `F:/docker/redis/data` 和 `F:/docker/redis/conf/redis.conf`。

因为该容器已提供教程后续使用的 Bloom 命令，本节保留现有 Redis 容器和数据，不执行删除、降级或重建。

## 验证

使用随机 Redis key 验证后已删除该 key：

| 命令 | 结果 |
| --- | --- |
| `BF.ADD <key> foo` | `1` |
| `BF.EXISTS <key> foo` | `1` |
| `BF.EXISTS <key> bar` | `0` |
| `BF.MADD <key> quan xiao` | `1, 1` |
| `BF.MEXISTS <key> quan xiao` | `1, 1` |

## 版本差异

本机 RedisBloom 版本为 Redis 8 自带的 8.10.1，与教程使用的 2.2.18 不同。教程后续所需的 `BF.ADD`、`BF.EXISTS`、`BF.MADD`、`BF.MEXISTS` 均已在 Docker Redis 中实测可用；若后续遇到版本行为差异，再按具体报错处理。
