# 21.4 笔记分词搜索

- 新增 `POST /search/note`，查询 `note` 索引的标题和话题，使用 `function_score` 按点赞、收藏、评论数加权，按 `_score` 倒序分页，并对标题做 `<strong>` 高亮。
- 新增笔记搜索入参/出参 VO、索引字段常量、Service 与 Controller；点赞数通过 `NumberUtils` 格式化，更新时间解析为 `LocalDateTime`。
- 验证：JDK 17 打包成功；随机临时笔记搜索返回 1 条，标题高亮正确，点赞数返回 `9876`；测试文档删除后索引数量恢复为 3。
- 风险：教程 `NoteIndex` 读取 `nickname/avatar`，而现有 ES `note` mapping 使用 `creator_nickname/creator_avatar`；本节保留教程字段名，实测作者昵称和头像为空。建议后续统一索引映射与代码字段名。
