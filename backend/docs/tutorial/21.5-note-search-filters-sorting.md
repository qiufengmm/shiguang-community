# 21.5 笔记搜索过滤与排序

- 扩展 `SearchNoteReqVO`，支持 `type` 笔记类型筛选和 `sort` 排序；新增 `NoteSortTypeEnum` 映射排序值。
- 搜索查询使用 bool filter 精确筛选图文/视频类型；支持按发布时间、点赞数、评论数、收藏数倒序，未指定或无效排序值时保留教程中的综合评分。
- 验证：JDK 17 执行 `mvn -pl xiaohashu-search -am -DskipTests package` 成功；启动搜索服务后，通过 `POST /search/note` 实测 type=0/1 过滤，以及 sort=0/1/2/3 四种排序，结果均符合预期。临时 ES 文档逐条删除，`note` 索引数量恢复为 3。
- 风险：搜索结果解析将 ES 返回的 `id` 直接强转为 `Long`。当 ES source map 将落在 32 位范围内的 ID 表示为 `Integer` 时会抛出 `ClassCastException`。本次用大于 32 位的随机 ID 完成接口验证；本节遵循教程未改动该解析逻辑。
