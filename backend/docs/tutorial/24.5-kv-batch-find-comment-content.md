# 24.5 KV 服务：评论内容批量查询接口

- KV API 新增批量查询请求/响应 DTO 和 Feign 方法；KV 服务新增 Cassandra Repository 派生查询，按 `noteId`、`yearMonth` 集合、评论正文 UUID 集合批量读取正文，并提供 `POST /kv/comment/content/batchFind`。
- 验证：JDK 17 下 Feign 契约测试和 Cassandra HTTP 集成测试通过；KV 服务打包并在 8084 启动。实际先通过 batchAdd 写入两个不同月份的随机正文，再调用 batchFind，确认两个 UUID 与正文都匹配；测试分区记录已清理。
