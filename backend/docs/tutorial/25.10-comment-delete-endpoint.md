# 25.10 评论删除接口开发

## 本节实现

- 新增 `DeleteCommentReqVO` 和 `POST /comment/delete`。
- 删除前校验评论存在，并确认当前用户是评论作者；否则返回对应业务错误。
- 在 MySQL 编程式事务中删除评论元数据，并通过 KV Feign 接口删除 Cassandra 正文。
- 按评论级别删除 Redis ZSet 成员和评论详情，再异步发送本地缓存失效消息及评论删除消息。

## 验证

- JDK 17 下评论服务及其依赖模块测试通过：35 项测试，0 失败、0 错误。
- 评论服务打包成功。
- 实际请求 `POST /comment/delete` 返回 `success=true`；日志确认 MySQL 删除 1 行，两个 RocketMQ 消息均返回 `SEND_OK`。
- 用随机 ID 向 Cassandra、MySQL 和 Redis 写入测试记录；接口调用后 MySQL 行数、Cassandra 正文数、Redis 详情键和列表成员均为 0，测试数据已清理。
- 原先占用 8084 的 KV 进程保持运行；本次用当前 KV 代码临时在 18084 启动，并将本次评论服务进程的 KV Feign URL 指向 18084，以验证正文删除链路。
- 实现遵循教程。

## 风险

`TransactionTemplate` 管理的是评论服务本地 MySQL 事务，Feign 调用的 Cassandra 删除不参与这个事务。远程删除成功后若本地事务再失败，跨服务状态可能不一致；本节按教程的实现方式保留。
