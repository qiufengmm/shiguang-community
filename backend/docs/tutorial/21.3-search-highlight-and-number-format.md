# 21.3 用户昵称高亮与数量转换

- 用户搜索请求新增 `nickname` 高亮，使用 `<strong>` 和 `</strong>` 包裹命中的昵称片段，并在响应中增加 `highlightNickname`。
- 在 `xiaoha-common` 增加 `NumberUtils.formatNumberString`：小于 1 万展示原值，小于 1 亿展示万单位并向下保留 1 位，达到 1 亿显示 `9999万`；响应中的 `fansTotal` 改为字符串。
- 验证：JDK 17 打包成功；以随机临时 ES 文档实测到高亮与 `137623 → 13.7万`，再删除该文档，`user` 索引数量恢复为 2。
- 风险：现有 ES 用户文档的 `fans_total` 为 `null`，传给 `NumberUtils.formatNumberString(long)` 会发生拆箱异常；本节按教程保留实现，教程的宽泛异常捕获随后会令响应 `data` 为 `null`。
