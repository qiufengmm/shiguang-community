# 24.6 评论分页查询接口（1）

- 评论服务新增 `POST /comment/list`，按笔记分页读取一级评论并按热度降序排列；每条一级评论最多带上最早的一条二级回复。
- 从 `t_note_count` 读取评论总数；新增 `NoteCountDO`、Mapper 查询和一级/二级评论分页 SQL。评论正文通过 KV 服务批量查询，头像和昵称通过用户服务批量查询，再组装为递归评论 VO。
- 验证：JDK 17 下评论服务定向测试 2 项通过，评论服务与 user-biz 均打包成功。启动评论服务（8093）和 user-biz（临时 8088，因 8082 被 QQ 占用），真实发布随机根评论和回复后调用 `/comment/list`，核对总数、评论正文、回复正文及两位用户昵称均正确。
- 测试数据已清理并复核：MySQL 评论及计数行均为 0，Cassandra 正文行和 Redis 首回复键均不存在。
- 教程原样实现，保留以下边界问题供后续修正：评论总数为空时调用 `PageResponse.success(null, pageNo, pageSize)`，现有三参数重载会把 `pageSize` 当 `totalCount`；用户批量接口最多接受 10 个 ID，而一页最多可能涉及 20 位用户；用户 RPC 为空时教程辅助方法会解引用空 Map；KV 批量查询参数要求非空，但全为图片评论时会传空列表。
