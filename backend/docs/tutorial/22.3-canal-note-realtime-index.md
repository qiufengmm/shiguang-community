# 22.3 自定义 Canal 消费：笔记实时增量 ES 索引

- 搜索服务增加 MyBatis、MySQL Connector 和 Druid；新增 `SelectMapper`，查询笔记索引字段及计数，并在 `CanalSchedule` 中处理 `t_note` 的 INSERT、公开状态 UPDATE、仅自己可见/逻辑删除/下架删除。
- 增加 MyBatis mapper XML 路径配置、`@MapperScan` 和开发库连接配置。仓库中其他 MyBatis 服务使用相同的 `classpath:/mapper/**/*.xml` 路径；漏配时运行日志报 `Invalid bound statement`，补齐后失败批次重放成功。
- 验证：JDK 17 下搜索服务 `package` 成功并启动；随机新增笔记后 ES 文档由 404 变为存在，普通标题更新覆盖成功；`visible=1` 删除文档、改回公开后重新建立，`status=2` 再次删除。测试笔记已从 MySQL 删除，ES 中确认 404；搜索服务接口返回 HTTP 200。
- 教程 SQL 写入字段 `img_uris`，现有索引/搜索代码使用 `cover`；本次实测 `_source` 中 `cover` 为 null。同时教程 SQL 未映射现有索引中的 `creator_nickname`、`creator_avatar` 字段。按教程保留原样，后续建议统一 SQL、索引映射和响应字段。
- 教程会将 `t_user` 的整行 `columnMap` 写入应用日志，其中包括密码哈希和手机号；按教程保留，生产环境应过滤敏感字段。
