# 25.6 MQ 批量消费：评论点赞、取消点赞批量写库

## 本节实现

- 新增 `LikeUnlikeComment2DBConsumer`，独立消费 `CommentLikeUnlikeTopic`，使用专属消费组、顺序消费和最多 30 条的批量拉取配置。
- 使用 `RateLimiter.create(5000)` 控制数据库写入速率；消费异常时暂停当前队列，成功后确认消息。
- 将每批消息按 `commentId`、`userId` 分组，只保留同一用户对同一评论按 `createTime` 排序后的最后一次操作。
- 批量取消点赞使用 MyBatis `batchDelete`；批量点赞使用 `batchInsert`，通过 `ON DUPLICATE KEY UPDATE id=id` 保持重复消息可安全重试。
- Spring Bean 显式命名，避免与现有 `Comment2DBConsumer` 冲突；服务销毁时关闭 RocketMQ 消费者。

## 验证

- JDK 17 下 comment-biz reactor 测试 26 项全部通过，包含消费组 Bean 配置、批量操作去重和 Mapper SQL 接口测试；历史 RocketMQ 集成测试 `MQTests` 按项目既有约定排除。
- Maven `-DskipTests package` 成功；评论服务已启动在 8093，RocketMQ 消费组 `xiaohashu_group_CommentLikeUnlikeTopic` 在线。
- 通过评论点赞接口发送随机 `Like` 事件，确认消费者将点赞记录写入 Docker MySQL；再发送随机 `Unlike` 事件，确认批量删除生效。
- 测试后删除随机评论/点赞行和 Bloom key，并确认记录数与 key 均为 0。
