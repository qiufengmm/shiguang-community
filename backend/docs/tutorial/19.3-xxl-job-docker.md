# 19.3 Docker 搭建 XXL-JOB 调度中心

沿用教程的 XXL-JOB 2.4.1、数据库 `xxl_job` 和宿主机端口 7777。按当前项目的环境约定使用 Docker 启动调度中心。

## 初始化数据库

`database/19.3-xxl-job-2.4.1.sql` 保存教程给出的完整初始化脚本。首次安装且 `xxl_job` 库尚未初始化时，在项目根执行：

```powershell
Get-Content -Raw database/19.3-xxl-job-2.4.1.sql |
    docker exec -i -e MYSQL_PWD=123456 mysql8.0 mysql --default-character-set=utf8mb4 -uroot
```

脚本包含建表和初始用户、示例执行器、停止状态的示例任务。已有数据库需要先检查结构，避免重复初始化。

## 启动调度中心

```powershell
docker compose -f infra/xxl-job/compose.yaml up -d
docker logs --tail 50 xxl-job-admin
```

若已配置的 Docker 镜像加速源出现 TLS 超时，可直接从官方 Registry 拉取同一版本，再添加本地标签：

```powershell
docker pull registry-1.docker.io/xuxueli/xxl-job-admin:2.4.1
docker tag registry-1.docker.io/xuxueli/xxl-job-admin:2.4.1 xuxueli/xxl-job-admin:2.4.1
docker compose -f infra/xxl-job/compose.yaml up -d --pull never
```

访问 `http://localhost:7777/xxl-job-admin/`。教程的初始账号为 `admin`，密码为 `123456`。

容器内部监听 8080，映射至宿主机 7777。容器通过 Docker Desktop 的 `host.docker.internal:3306` 访问现有 `mysql8.0` 容器发布的 MySQL 端口。数据库文件由现有 MySQL 挂载持久化，调度中心日志使用命名卷。

Compose 使用项目已确认的开发数据库密码作为默认值；如需覆盖，可在当前 PowerShell 进程设置 `XXL_JOB_MYSQL_PASSWORD` 后重新执行启动命令。

本节使用镜像默认的执行器通信 Token `default_token`，19.4 的执行器配置需与调度中心保持一致。
