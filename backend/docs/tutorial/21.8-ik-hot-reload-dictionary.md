# 21.8 IK 自定义热重载词典接口

- 搜索服务新增 `GET /search/ext/dict`，从配置路径读取 UTF-8 词典内容，并返回 `Last-Modified`、`ETag` 和 `text/plain;charset=UTF-8`。`application-dev.yml` 指向现有 Docker 挂载路径 `F:\docker\elasticsearch\config\analysis-ik\custom\mydict_hot_update.dic`。
- 词典初始包含“打工人”“打工魂”“社畜”；IK 配置启用 `http://host.docker.internal:8092/search/ext/dict`，复用现有 `es7` 容器。
- 验证：JDK 17 打包成功；接口返回 HTTP 200、词典内容及所需响应头。重启 ES 后首批词生效；再将“社死”追加到词典，ETag 随内容变化，约 40 秒后 `_analyze` 自动识别“社死”，该次热更新未重启 ES。
- 风险：按教程实现，`Files.lines()` 未显式关闭流；异常时实现返回 `null`。热更新词典路径依赖本机 Docker 挂载目录。
